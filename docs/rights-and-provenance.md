# Rights and provenance

MightyMatica restores the mathematical collection created by Yuri Remizov and
the original site authors. Attribution belongs with the restored collection
and its activities. A native adaptation must be described as an adaptation
unless its behavior and content have actually been checked against the source.
Being in the catalog does not mean an original has already been restored.

## Reference layers

The preserved site snapshot is `mightymatica-archive-2026-08-09`; its `raw-site`
tree supplies original HTML, SWFs, and linked preview artwork. The separate
`mightymatica-source-recovery` tree supplies the recovery inventories,
decompiled ActionScript, P-code, text, vectors, timelines, and approximate XFL.
These reference trees remain read-only and are not bundled into this app.

The recovery README distinguishes compiled/decompiled artifacts from genuine
authored sources. Falling Figure additionally has authenticated FLA,
ActionScript, assets, and Git history preserved from `ignatremizov/Figure`.
That exception must not be generalized into a claim that every recovered
project has its original authored source.

`src/content/legacy.json` records exact relative source paths and original
SHA-256 hashes. `src/content/original-pages.json` records original preview paths
and hashes for the selected raster media under `public/media/catalog/`.
These hashes support provenance and reproducibility, not ownership claims.
Only selected linked previews are copied; no Flash executable, archived script,
analytics, or private contact details are imported.

## No blanket media license

The FFDec Canvas runtime has a separate software-license boundary: FFDec
26.2.1's `ffdec_lib` is LGPLv3. Public notices and LGPL/GPL companion texts live
under `public/licenses/`; corresponding source, readable converted baselines,
final-module references and hashes live under `third-party/ffdec/`.
See that directory's README for upstream evidence and modifications dated
2026-10-31. These terms do not relicense independent application code or art.

Original site content belongs to Yuri Remizov, the site authors, or their
respective rights holders. This restoration does not automatically place that
content under MIT or any license chosen for new application code.

M. C. Escher artwork and adaptations, third-party illustrations, photographs,
fonts, recordings, sound effects, and other incorporated media require their
own attribution and rights assessment. An image's presence in the old public
site, a recovered SWF, or this preservation inventory is not evidence of a
redistribution license. No third-party permissions are asserted here.

Before public distribution, review each retained original media item and any
family-specific extracted assets; obtain permission, document an applicable
license or other authorized basis, or replace/remove the asset. Keep required
credits alongside any authorized use. The selected catalog thumbnails remain
original media subject to that review, even where they look like simple lesson
diagrams. No determination that every item is cleared for publication has
been made.

Descriptions extracted from original HTML retain original wording where
selected. Authorship attribution in the generated metadata is editorial
provenance, not a claim that an individual page contains that exact credit.
Contact pages, address images, emails, and personal biographies are not needed
for the restoration and are intentionally not harvested.
